# One presidential term (대) per line, columns separated by a single TAB. The header row
# just above the data names the columns and is commented out like every other non-data line.
#
#   number      the 대 (term number) as Korean usage counts it: one per election, so a
#               person re-elected keeps one line per term with consecutive numbers
#               (이승만 is 1, 2 and 3; 박정희 is 5 through 9; 전두환 is 11 and 12)
#   term_start  ISO-8601 date (yyyy-MM-dd)
#   term_end    ISO-8601 date, or '-' for the incumbent
#   name        the only column that may contain spaces
#   party       single token; '/' separates successive affiliations during the term,
#               '무소속' is independent
#   born        birth year
#   died        death year, or '-' when living
#
# Acting presidents (권한대행) hold no 대 and are not listed. A suspension during a term
# (노무현 2004-03-12 ~ 2004-05-14, 박근혜 2016-12-09 ~ 2017-03-10, 윤석열 2024-12-14 ~
# 2025-04-04) does not split the line; the term ends on the day the office was vacated.
#
# Lines starting with '#' and blank lines are comments.
#
