# other non-data line.

#   number      the 代 (term number) as Japanese usage counts it: one per appointment, so a
#               cabinet re-formed after a general election starts a new 代 and a person keeps
#               one line per 代 (吉田茂 is 45 and 48 through 51; 安倍晋三 is 90 and 96 through 98)
#   term_start  ISO-8601 date (yyyy-MM-dd)
#   term_end    ISO-8601 date, or '-' for the incumbent
#   name        the only column that may contain spaces
#   party       single token; '/' separates successive affiliations during the term,
#               '無所属' is independent; 民主党 names both the 1947-1950 and the 1998-2016 party
#   born        birth year
#   died        death year, or '-' when living
#
# Interim and acting prime ministers (兼任, 臨時代理: 三条実美, 内田康哉, 伊東正義, 青木幹雄, ...)
