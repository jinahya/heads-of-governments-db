= Exercises
:toc: left
:toclevels: 3

The exercises on `db/heads_of_governments.sqlite3`: a section for each table, with a section for each level, and, at the end, a section for the schema as a whole.
Each exercise states the request it answers; the SQL that answers it is in the `.sql` file, under the same id.
The ids are registered in `EXERCISES.yaml`.

Parameters are bind variables (`:name`); the `sqlite3` shell binds one with `.parameter set :name 'value'`, and an IDE prompts for them when a statement runs.
An exercise with a parameter, or one that measures to `date('now')`, shows no output, since what it gives back depends on the value or the day.

Run a file as a whole:

[source,sh]
----
sqlite3 -readonly db/heads_of_governments.sqlite3 < src/test/sql/<file>.sql
----

== head

The `head` table: a row per term of a head of government.

=== Basic

[[HOG-HEAD-B-01]]
==== HOG-HEAD-B-01: Who held office on a day

A reader gives a date and wants each country's head on that day.
A country whose office was vacant is absent.

.`head_exercises_01_basic.sql`, HOG-HEAD-B-01
[%collapsible]
====
[source,sql]
----
SELECT country, number, name, party, term_start, term_end
FROM head
WHERE term_start <= :date
  AND (term_end IS NULL OR term_end >= :date)
ORDER BY country ASC
----

==== HOG-HEAD-B-04: Terms by name

A reader types part of a name and wants every term of anyone matching it.

[source,sql]

[[HOG-HEAD-I-07]]
==== HOG-HEAD-I-07: The latest terms of each country

Per country, the :n most recent terms, oldest of them first.
Terms, not persons: a head re-elected appears once per term. term_start is NOT NULL and distinct within a country, so the numbering has no ties.

.`head_exercises_02_intermediate.sql`, HOG-HEAD-I-07
[%collapsible]
====
[source,sql]
----
SELECT country, number, name, term_start, term_end
FROM (SELECT h.*, ROW_NUMBER() OVER (PARTITION BY country ORDER BY term_start DESC) AS latest_rn
      FROM head AS h)
WHERE latest_rn <= :n
ORDER BY country ASC, term_start ASC
----

[[HOG-HEAD-I-08]]
==== HOG-HEAD-I-08: The first and the latest terms of each country

Per country, its first :n terms and its most recent :n, each row saying which it is.
A row is 'first' when it is among the first :n, so with a country of 2 * :n terms or fewer the two sets overlap and 'first' wins.

.`head_exercises_02_intermediate.sql`, HOG-HEAD-I-08
[%collapsible]
====
[source,sql]
----
SELECT country,
       CASE WHEN first_rn <= :n THEN 'first' ELSE 'latest' END AS which,
       number,
       name,
       term_start,
       term_end
FROM (SELECT h.*,
             ROW_NUMBER() OVER (PARTITION BY country ORDER BY term_start ASC)  AS first_rn, ROW_NUMBER() OVER (PARTITION BY country ORDER BY term_start DESC) AS latest_rn
      FROM head AS h)
WHERE first_rn <= :n
   OR latest_rn <= :n
ORDER BY country ASC, term_start ASC
----

[[HOG-HEAD-A-02]]
==== HOG-HEAD-A-02: Longest in office

Per country, the person with the most days in office over all their terms, counting an open term to today; ties share the place.

.`head_exercises_03_advanced.sql`, HOG-HEAD-A-02
[%collapsible]
====
[source,sql]
----
SELECT country, name, terms, days
FROM (SELECT country,
             name,
             COUNT(*)                                                                                  AS terms,
             CAST(SUM(julianday(COALESCE(term_end, date ('now'))) - julianday(term_start)) AS INTEGER) AS days,
             RANK()                                                                                       OVER (PARTITION BY country
                 ORDER BY SUM(julianday(COALESCE(term_end, date('now'))) - julianday(term_start)) DESC) AS place
      FROM head
      GROUP BY country, name)
WHERE place = 1
ORDER BY country ASC
----

[[HOG-HEAD-A-03]]
==== HOG-HEAD-A-03: The longest run of one party

Per country, the longest unbroken run of consecutive terms held by the same party, with when it began and ended; a run is counted in terms, not days, and a succession ('UNR/UDR') is a party of its own.

.`head_exercises_03_advanced.sql`, HOG-HEAD-A-03
[%collapsible]
====
[source,sql]
----
WITH ordered AS (SELECT country,
                        party,
                        term_start,
                        term_end,
                        ROW_NUMBER() OVER (PARTITION BY country ORDER BY term_start)        AS seq, ROW_NUMBER() OVER (PARTITION BY country, party ORDER BY term_start) AS seq_in_party
                 FROM head),
     runs AS (SELECT country,
                     party,
                     COUNT(*)                              AS terms,
                     MIN(term_start)                       AS since,
                     MAX(COALESCE(term_end, date ('now'))) AS until
              FROM ordered
              GROUP BY country, party, seq - seq_in_party),
     placed AS (SELECT *, RANK() OVER (PARTITION BY country ORDER BY terms DESC, since ASC) AS place
                FROM runs)
SELECT country, party, terms, since, until
FROM placed
WHERE place = 1
ORDER BY country ASC
----

                           name,

                           position + 1,

[[HOG-HEAD-A-05]]
==== HOG-HEAD-A-05: Predecessor and successor

For a person named exactly, each of their terms with who held the office immediately before and after it in that country; the incumbent has no successor.

.`head_exercises_03_advanced.sql`, HOG-HEAD-A-05
[%collapsible]
====
[source,sql]
----
SELECT country, number, term_start, term_end, predecessor, successor
FROM (SELECT country,
             number,
             name,
             term_start,
             term_end,
             LAG(name) OVER (PARTITION BY country ORDER BY term_start)  AS predecessor, LEAD(name) OVER (PARTITION BY country ORDER BY term_start) AS successor
      FROM head)
WHERE name = :name
ORDER BY country ASC, term_start ASC

==== HOG-OFFICE-A-01: What number counts, in a phrase

.`office_exercises_03_advanced.sql`, HOG-OFFICE-A-01
[%collapsible]

           WHEN comma > 0 AND (semicolon = 0 OR comma < semicolon) THEN SUBSTR(numbering, 1, comma - 1)

[[HOG-SCHEMA-A-01]]
==== HOG-SCHEMA-A-01: Each office's longest-serving head

Per office, the person with the most days in office over all their terms, with the title they held; ties share the place.

.`_schema_exercises_03_advanced.sql`, HOG-SCHEMA-A-01
[%collapsible]
====
[source,sql]
----
SELECT country, head_title, name, terms, days
FROM (SELECT g.country,
             g.head_title,
             h.name,
             COUNT(*)                                                                                   AS terms,
             CAST(SUM(julianday(COALESCE(h.term_end, date('now'))) - julianday(h.term_start)) AS INTEGER) AS days,
             RANK() OVER (PARTITION BY g.country
                 ORDER BY SUM(julianday(COALESCE(h.term_end, date('now'))) - julianday(h.term_start)) DESC) AS place
      FROM office g
               JOIN head h ON h.country = g.country
      GROUP BY g.country, g.head_title, h.name)
WHERE place = 1
ORDER BY country ASC
----
